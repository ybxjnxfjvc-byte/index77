# Mini threat model — index77

## Scope

Публичный учебный кейс `Estudiamos · Система обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Минимизация данных / приватность / ретенция

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Сбор лишних данных | Форма просит поля без цели | Data minimization: только необходимые поля |
| T2 | Бессрочное хранение | Учебные результаты сохраняются без срока | Retention policy и удаление |
| T3 | ПДн в логах | Контакты/имя пишутся целиком | Redaction/pseudonymization |
| T4 | Передача третьей стороне | Данные уходят во внешний сервис незаметно | Инвентаризация recipients/endpoints |
| T5 | Смешение учебных и реальных данных | В демо используются реальные контакты | Только синтетические/обезличенные тестовые данные |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
